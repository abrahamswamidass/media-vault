Connector Catalog

🗄️

nas

Source of truth · mounted SMB/NFS/local
readstat soft-delete → trashcopy-in

Fully working today. Delete moves to <root>/_trash (reversible). Path-escape guarded. Ships a cheap dedup fingerprint in stat.

🔵

drive

Google Drive · the only fully-automatable cloud
read*delete* (perm/trash) uploadSAFE mode

*Runs as dry-run until DRIVE_LIVE=1 + OAuth wired. --permanent reclaims paid space; default is Drive trash.

📦

archive

Takeout / Amazon export · read-only index
readstat +JSON sidecar deleteupload

Point it at an exported folder. One code path indexes both Google Photos Takeout and Amazon “Request My Data” dumps.

📤

amazon

Write-only · watched-folder staging
list stagedstage (upload) deleteno API

Copies cherry-picks into a dated album folder; Amazon’s official desktop app auto-uploads. Zero fragile code.

Command Catalog — copy & try

Safety: delete and upload are dry-run unless you add --commit. NAS delete only moves to trash. Add --json to any command for machine output.
🔎 caps — what can this connector do?SAFE
Print read/delete/upload capability flags for a connector.
python3 mediavault.py nas caps --root /mnt/nas
📂 list — browse a folderSAFE
List items under a prefix. Streams, cheap, capped by --limit.
python3 mediavault.py nas list --root /mnt/nas --prefix Photos/2026-01 --limit 50
📑 stat — full metadata + dedup fingerprintSAFE
Size, mime, mtime, and a size+head/tail quick-hash you’ll use for dedup.
python3 mediavault.py nas stat --root /mnt/nas "Photos/2026-01/img_001.jpg"
👁️ read — safe byte peekSAFE
Read the first N bytes (hex) to verify access without pulling whole files over the mount.
python3 mediavault.py nas read --root /mnt/nas "Photos/2026-01/img_001.jpg" --peek 32
🗑️ delete — dry-run firstGUARDED
Shows exactly where the file would move. Nothing changes.
python3 mediavault.py nas delete --root /mnt/nas "Photos/junk.jpg"
🗑️ delete — commit (soft, to trash)GUARDED
Actually moves the file to <root>/_trash, preserving structure. Reversible.
python3 mediavault.py nas delete --root /mnt/nas "Photos/junk.jpg" --commit
📤 amazon — stage a cherry-pickGUARDED
Copies a file into a dated album folder the Amazon desktop app watches and auto-uploads.
python3 mediavault.py amazon upload --root /mnt/nas/_AmazonUpload ./pic.jpg --commit
📦 archive — index a Takeout / export dumpSAFE
Read an exported folder; stat pulls Takeout JSON sidecars into extra.takeout.
python3 mediavault.py archive stat --root /mnt/exports/takeout "Photos/IMG_2201.jpg"
🔵 drive — delete (safe-mode until live)GUARDED
Prints the exact action (--permanent = reclaim space). No API call until DRIVE_LIVE=1.
python3 mediavault.py drive delete --root creds.json "<fileId>" --permanent --json

Try It Out — 60-second sandbox

No NAS handy? Build a fake share and run the exact same commands against it.

1
# make a throwaway share with a few files
mkdir -p /tmp/fakenas/Photos/2026-01 /tmp/fakenas/Docs
echo hi > /tmp/fakenas/Photos/2026-01/img_001.jpg
echo junk > /tmp/fakenas/Photos/junk.jpg
2
# browse + inspect (safe)
python3 mediavault.py nas list --root /tmp/fakenas --prefix Photos/2026-01
python3 mediavault.py nas stat --root /tmp/fakenas "Photos/2026-01/img_001.jpg"
3
# delete: dry-run, then commit (file lands in _trash)
python3 mediavault.py nas delete --root /tmp/fakenas "Photos/junk.jpg"
python3 mediavault.py nas delete --root /tmp/fakenas "Photos/junk.jpg" --commit
ls -R /tmp/fakenas/_trash
